# ChatWise

### Fast, minimal AI chat for power users

ChatWise is a lightning-fast desktop AI assistant built for efficiency. With keyboard-first navigation, instant model switching, and a clean distraction-free interface, it's the AI chat app for people who value speed.

<br>

---

## Features

| | |
|:---|:---|
| **Keyboard First** | Navigate, search, and run commands entirely from the keyboard |
| **Instant Switching** | Swap between models mid-conversation without losing context |
| **Minimal Design** | A focused interface with no bloat — just you and the AI |
| **Local Model Support** | Connect to Ollama and other local inference servers |
